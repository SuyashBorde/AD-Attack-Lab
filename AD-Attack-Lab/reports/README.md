# Reports

Polished, client-style deliverables go here (PDF, same format as the VulnScan Lab reports).

Suggested filename: `AD_Attack_Lab_Report.pdf`

Suggested sections (mirrors your existing VulnScan Lab report style):
1. Executive Summary
2. Scope & Methodology
3. Findings (with CVSS-style severity + screenshots)
4. Attack Narrative (AS-REP → Kerberoast → Lateral Movement)
5. Remediation Recommendations
6. Appendix (raw command output, tool versions)

Once you've finished Kerberoasting and lateral movement, this is the file to build —
happy to help generate it as a proper PDF/Word doc once the attack chain is complete.
